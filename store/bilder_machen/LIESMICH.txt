STORE-BILDER NEU MACHEN
=======================

Erzeugt die acht Bilder in store/screenshots, je 1080 x 1920, PNG ohne
Alphakanal - so, wie Google sie fuer Telefone will. Zuletzt am 01.10.2026.

Die Bilder entstehen in einem unsichtbaren Chrome am PC, nicht auf dem
Handy. Das hat drei Gruende:
  - Das Handy braucht dafuer keine geaenderte Bildschirmgroesse.
  - Kein echter Lernstand wird angefasst; der Vorfuehrstand liegt in
    testdaten/zmaj-screenshots.json.
  - Keine Statusleiste, keine Uhrzeit, kein Akkustand im Bild.

Die Breite ist 360 Punkte, so breit wie Ajdins S21 in der App misst.
Den Zurueck-Knopf oben rechts blendet das Skript aus: es gibt ihn nur
im Browser am PC, die App hat ihn nicht (Android hat eine eigene
Zurueck-Taste). Mit ihm schob sich bei 360 Punkten die Muenzanzeige
ueber die Herzen - in der App kommt das nicht vor.


NEU: OHNE GIT BASH UND IN JEDER SPRACHE
--------------------------------------
bilder_playwright.py macht dieselben acht Bilder auf Windows, Linux und
Mac, liefert web/ selbst aus und kennt jede Sprache der App:

     python -m pip install playwright pillow
     python -m playwright install chromium
     python store/bilder_machen/bilder_playwright.py                  (Deutsch)
     python store/bilder_machen/bilder_playwright.py --sprache en --montage docs/assets/screenshots-en.png

Der alte Weg unten funktioniert weiter.


SO GEHT ES (Git Bash, im Projektordner)
--------------------------------------
1. Die App ausliefern:
     cd web && python -m http.server 8777 --bind 127.0.0.1

2. Chrome ohne Fenster starten (zweites Terminal):
     "/c/Program Files/Google/Chrome/Application/chrome.exe" --headless=new \
       --remote-debugging-port=9444 --user-data-dir="$TEMP/zmaj_chrome" \
       --hide-scrollbars --mute-audio --lang=de-DE about:blank

3. Bilder machen:
     sh store/bilder_machen/bilder_machen.sh

Python ist das von Thonny; es braucht das Paket websockets.


MIT UEBERSCHRIFT UND FEATURE-GRAFIK JE SPRACHE (seit 11.10.2026)
--------------------------------------------------------------
beschriften.py setzt ueber jedes Rohbild eine kurze Ueberschrift und macht
die Feature-Grafik (web/_feature.html?sprache=xx) als JPEG ohne Alpha:

     python store/bilder_machen/beschriften.py ROH ZIEL de en tr sv nl nb da fr

ROH/<sprache>/ enthaelt die acht Rohbilder. Die Texte stehen in
UEBERSCHRIFTEN in beschriften.py. Braucht Chrome und websockets.

Die Store-Bilder sind seit v5 (15.10.2026) dunkel. Dafuer die Rohbilder mit
--aussehen dunkel machen; ohne die Angabe stellt Playwright hell ein (wie
bisher).


TABLETS: 7 UND 10 ZOLL (seit 30.10.2026)
---------------------------------------
Dieselben acht Bilder, dieselben Ueberschriften, die App in Tablet-Breite in
einem schlichten Tablet-Rahmen. Rohbilder je Sprache:

     python store/bilder_machen/bilder_playwright.py --geraet tablet7  --aussehen dunkel --sprache de --ziel ROH7/de
     python store/bilder_machen/bilder_playwright.py --geraet tablet10 --aussehen dunkel --sprache de --ziel ROH10/de

  tablet7   Bildschirm 600 x 960 Punkte (wie ein Nexus 7), mal 2
  tablet10  Bildschirm 800 x 1280 Punkte (uebliches 10-Zoll-Tablet), mal 2

Die App ist eine Spalte bis 540 Punkte; auf dem 10-Zoll-Tablet bleibt links
und rechts Rand, und unter einer Lektion bleibt der Bildschirm leer. So sieht
sie dort wirklich aus. Dann Ueberschrift und Rahmen:

     python store/bilder_machen/beschriften.py --geraet tablet7  ROH7  ZIEL7  de en tr sv nl nb da fr
     python store/bilder_machen/beschriften.py --geraet tablet10 ROH10 ZIEL10 de en tr sv nl nb da fr

Ergebnis 1080 x 1920 (7 Zoll) bzw. 1440 x 2560 (10 Zoll), 9:16, PNG ohne
Alpha, Name <sprache>_tab7_01-start.png bzw. <sprache>_tab10_... Ohne
Feature-Grafik, die gibt es je Sprache nur einmal. Hochladen: Play Console,
Store-Eintrag, Grafiken, "Screenshots fuer 7-Zoll-Tablets" bzw.
"10-Zoll-Tablets", je Sprache im jeweiligen Sprach-Eintrag.


WAS AUF DEN BILDERN IST
-----------------------
  01-start        Startseite: Lernserie, Weitermachen, Tagesaufgaben
  02-lernpfad     Sektion 1 mit bestandenen und gesperrten Levels
  03-neues-wort   erste Karte einer Lektion
  04-auswahl      Auswahlaufgabe "Wie viel kostet das?"
  05-grammatik    Grammatikaufgabe (bis 11.10.2026: 04 nach der Antwort)
  06-luecke       Lueckensatz mit eingetippter Antwort
  07-geschichte   Geschichte "Na pijaci" mit angetipptem Wort
  08-wiederholen  Reiter Wiederholen mit sieben Aufgaben

Die Lektion wird zufaellig zusammengestellt. Das Skript sucht sich die
Aufgaben darin selbst; Wort und Satz koennen also beim naechsten Lauf
andere sein.
