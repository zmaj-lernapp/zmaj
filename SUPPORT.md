# Getting help

- **Something in the app is wrong** (a word, a translation, a pronunciation):
  open a [language correction](https://github.com/zmaj-lernapp/zmaj/issues/new?template=language_correction.yml).
  This is the most valuable help there is.
- **A bug:** open a [bug report](https://github.com/zmaj-lernapp/zmaj/issues/new?template=bug_report.yml).
- **Using the dataset:** read [`data/DATASHEET.md`](data/DATASHEET.md), then ask in an issue.
- **Anything private:** zmaj.lernapp@gmail.com. The app's own feedback button
  writes to the same address.

This is a one-maintainer project. Answers usually come within a few days.
